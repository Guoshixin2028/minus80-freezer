# -80℃ 冰箱菌种管理台 · 云端版

NFC 碰触 → 打开网页 → 点选孔位登记 → 云端保存 → 搜索快速取菌 → 自动记录取出历史。

## 架构

```
手机(碰NFC手环) ──HTTP──> FastAPI 后端(app.py) ──> SQLite(data/freezer.db)
                              │
                              ├── static/index.html  前端页面(云端同步版)
                              └── data/backups/       每次保存自动快照(保留200份)
```

- **后端**：`app.py`（FastAPI + SQLite，单文件部署，无需安装 MongoDB）
- **前端**：`static/index.html`（由原 localStorage 版本改造为云端同步版）
- **并发安全**：乐观版本号（rev）校验，两人同时改数据时后保存者会收到 409 冲突提示，可选择「放弃我的修改」或「用我的版本覆盖」
- **数据安全**：每次成功保存自动写一份 JSON 快照到 `data/backups/`

## 快速开始（实验室电脑 / 树莓派）

```bash
cd server
pip install -r requirements.txt
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Windows 双击 `start.bat` 即可（自动建虚拟环境+装依赖+启动）。

手机连接**同一个实验室 WiFi**，访问 `http://<电脑局域网IP>:8000`（`ipconfig` / `ifconfig` 查看 IPv4）。

首次打开会自动写入一份示例数据，可在左侧「数据与统计 → 重置数据」里清空。

## NFC 手环 / 标签写入

用手机 App「NFC Tools」或微信小程序「NFC 写入」，把手环（建议 NTAG213/215 芯片）写成一个 **URL 记录**。
冰箱上挂两条手环，分别直达「存放」和「取菌」手机视图：

| 手环 | 写入的 URL | 碰环后的效果 |
|------|-----------|------|
| 存环（存放用） | `http://192.168.1.20:8000/?view=store&rack=铁架 1` | 直达**存放视图**：自动选中该铁架的盒子，只显示空孔位，点空位填表即存到云端 |
| 取环（取菌用） | `http://192.168.1.20:8000/?view=search` | 直达**取菌视图**：关键词 + 高级筛选找菌，点开看位置，一键登记取出并记录历史 |

- 存环若冰箱有多个铁架，可按层各挂一个：`rack=铁架 1` / `rack=铁架 2`（支持「精确名称 / 名称包含 / ID」三种匹配）。
- 两个视图顶部都有「返回管理台」入口，管理台（完整功能页）地址为 `http://192.168.1.20:8000/`。

管理台 URL 参数（不带 `view=` 时使用，同样支持「精确名称 / 名称包含 / ID」三种匹配）：

- `?rack=铁架 1` — 自动选中该铁架
- `?box=A1` — 自动选中名称含 A1 的盒子
- `?well=B3` — 自动打开 B3 孔位的详情面板

> 提示：正式部署建议绑定域名 + HTTPS（见下），iOS 对 https 链接的 NFC 支持更好。

## 公网部署（让任意网络都能访问）

任选其一：

1. **免费托管**（推荐 Render / Railway / Fly.io）：上传本目录，启动命令 `uvicorn app:app --host 0.0.0.0 --port $PORT`，自动获得 https 域名，把它写进 NFC 手环即可。
2. **校园网内穿透**：cloudflare tunnel / frp，把实验室电脑的 8000 端口映射出去。
3. **实验室电脑常驻**：最简单，手机连实验室 WiFi 直接用 IP 访问。

## 多人并发说明

- 每次保存携带版本号，若云端已被别人更新，会弹出冲突对话框：
  - **放弃我的修改**：加载云端最新版
  - **用我的版本覆盖**：强制写入（整库覆盖，慎用）
- 页面每 15 秒轮询一次云端版本，别人有更新时顶栏会出现橙色「云端有更新」按钮，点击即可加载。
- 顶栏右侧实时显示同步状态（已同步 / 同步中 / 离线 / 版本冲突）。

## 数据备份与迁移

- 自动备份：`data/backups/freezer-日期-r版本号.json`（保留最近 200 份）
- 手动备份：页面顶栏「导出备份」按钮（JSON 文件）
- 恢复：页面「导入」按钮，支持合并（追加）或覆盖
- 从旧 localStorage 版本迁移：在旧页面「导出备份」→ 在本页面「导入」即可，数据结构完全一致

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/db` | 获取 `{rev, db}`，空库返回 404 |
| PUT | `/api/db` | body `{rev, db, force?}`；rev 不匹配且未 force 时返回 409 + 最新数据 |
| GET | `/api/health` | 健康检查 |

## 后续演进方向

- 「保存人 / 操作人」目前仍为可编辑输入框 + 默认值（每台设备在「默认保存人」里设置）。接入正式登录（如实验室统一账号 / 企业微信 / Supabase Auth）后，可改为只读身份字段。
- 搜索目前匹配菌种/质粒/保存人/备注/孔位号，后端可扩展全文索引。
- 取出记录如需推送到群通知（如企业微信机器人），可在 `put_db` 中按 `takings` 差异触发 webhook。
