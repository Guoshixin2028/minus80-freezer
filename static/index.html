      准备就绪：点上面的按钮，把手环贴到手机背面摄像头附近，直到震动提示。
      1. 写入会覆盖手环里原来的内容
      2. 需要安卓 Chrome / Edge（89 或更高版本），且本页面必须是 https 打开
      3. 写好后锁屏再碰一次，能自动弹出网页就成功了
      4. 一根手环可反复重写；三根手环可分别写成 存 / 取 / 单
      这台设备的浏览器不支持网页直接写 NFC（iPhone 或桌面浏览器）。 请按下面方法用 App 写入：
      1. 复制上面的网址（点「复制」）
      2. 安装免费 App NFC Tools（Wakdev 出品）
      3. 写 → 添加记录 → 选「自定义 URL / 链接」→ 粘贴网址
      4. 点「写」并把手环贴到手机背面
